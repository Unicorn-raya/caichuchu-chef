# 燕麦鸡蛋饼

## 食材准备与处理

- **燕麦 50-75g**：
  - 必须用**即食/快熟燕麦片**（纯干燕麦片）。
  - 不要用需要久煮的钢切燕麦或生燕麦粒，否则煎完有硬芯。
- **鸡蛋 2 个**：
  - 打入碗中，搅打至蛋清蛋黄完全融合、颜色单一。
- **牛奶 100-150ml**：
  - 全脂奶更香，也可用等量清水替代。
- **黄油 5-10g**：
  - 润锅用，黄油奶香与燕麦最搭；也可用味道淡的食用油。
- **可选调味（咸口）**：
  - 盐 1g、黑胡椒少许，在调糊时加入。
- **可选调味（甜口）**：
  - 白糖/代糖 5-10g，或出锅后淋蜂蜜。
- **可选配料**：
  - 蔬菜碎叶（生菜、菠菜切碎）、胡萝卜碎、香肠丁、黑芝麻、芝士碎。
  - 蔬菜要提前切碎；易出水的蔬菜（如番茄）少放，否则饼难成型。
- **关键预处理——泡燕麦**：
  - 牛奶与燕麦混合，静置 3-5 分钟（用热牛奶泡 2 分钟更快）。
  - 直到燕麦吸饱水分呈黏稠糊状；燕麦没泡透，煎的时候饼会散、口感发硬。

## 详细做法

1. **泡燕麦**：
   - 燕麦倒入碗中，加入牛奶搅拌均匀。
   - 静置到黏稠状，判断标准：勺子划过能留下痕迹的程度。
2. **调糊**：
   - 将打散的鸡蛋液倒入燕麦牛奶中，继续搅拌至均匀黏稠。
   - 咸口此时加入盐、黑胡椒。
   - 想要饼更挺括不易散，可加 1-2 勺（约 15-20g）面粉增加黏性。
   - 面糊状态以"能缓慢流动、摊得开"为准，太稠补点牛奶。
3. **润锅**：
   - 平底锅（不粘锅最佳）放入黄油，先不开火或开最小火让黄油融化。
   - 转动锅子让油均匀覆盖锅底。
4. **摊饼**：
   - 把燕麦蛋糊倒入锅中，用锅铲或勺背从中心向外推开。
   - 摊成厚度均匀的圆饼（约 5-8mm 厚）；一次做不完分两次，小饼比大饼好翻面。
5. **撒料**：
   - 想加蔬菜碎、香肠丁、芝士碎的，趁表面还没凝固均匀撒上。
   - 轻轻压一压让配料嵌进糊里。
6. **小火煎制**：
   - 保持小火，煎 2-3 分钟。
   - 判断翻面时机：饼的边缘凝固变色、表面基本不流动、晃动锅子整张饼能滑动。
7. **翻面**：
   - 用宽锅铲从饼下整个穿过，快速果断翻面。
   - 翻面后再小火煎 1.5-2 分钟，至两面金黄。
8. **出锅**：
   - 切块或直接装盘。
   - 甜口可淋蜂蜜、撒糖粉；咸口可挤番茄酱、卷生菜食用。

## 关键技巧

1. **燕麦先泡透**：
   - 这是不成"散饼"的第一要素。燕麦吸足液体后糊化出黏性，才能把鸡蛋"粘"成饼。
   - 干燕麦直接混蛋液，煎出来必然散架、口感扎嘴。
2. **全程小火**：
   - 燕麦和牛奶都含糖和蛋白质，火大极易外糊内生。
   - 小火慢煎让热量穿透到中心；看到边缘上色过快就把锅端离火几秒降温。
3. **蛋液提前加盐（进阶）**：
   - 盐在蛋液中提前溶解能减弱蛋白质间的紧缩力，煎出来更嫩更蓬松。
   - 比出锅前撒盐效果好得多。
4. **用黄油配小火**：
   - 黄油烟点低，配合小火刚好，奶香与燕麦是绝配。
   - 若用普通油，选味道淡的玉米油，避免花生油味盖过麦香。
5. **翻面一张过**：
   - 翻面犹豫会把饼折裂；锅铲完全伸入饼底、手腕果断一翻。
   - 没把握就把饼先滑到盘子里，再扣锅翻转。

## 常见问题

1. **饼散了不成形**：
   - 原因：燕麦没泡透、面糊太稀、或没等凝固就翻动。
   - 解决：加 1-2 勺面粉增稠；等表面完全凝固再翻面。
2. **外面糊了里面湿软**：
   - 原因：火太大，热量只停留在表面。
   - 解决：小火慢煎，饼摊薄一点（不超过 8mm），必要时盖盖焖 1 分钟让中心熟透。
3. **口感干硬扎嘴**：
   - 原因：燕麦品种不对（用了需煮燕麦），或液体量不足。
   - 解决：换即食燕麦，牛奶加到能让燕麦泡成稠糊的量。
4. **粘锅**：
   - 原因：油太少、锅没润匀、或锅烧太热下面糊。
   - 解决：用不粘锅，黄油铺满锅底；锅太热面糊一下锅底部就结痂粘住，温热下锅即可。

## 变化做法

1. **蔬菜肉松卷饼版**：
   - 面糊中加胡萝卜碎、黑芝麻，煎好后铺上生菜、肉松/里脊肉丝。
   - 挤沙拉酱卷起来，堪比低脂煎饼果子。
2. **香蕉甜饼版**：
   - 半根香蕉压泥调入面糊，不加糖也有自然甜味。
   - 出锅撒肉桂粉，无盐无糖版适合给宝宝吃。
3. **燕麦麸皮版**：
   - 用燕麦麸皮替换燕麦片，同样泡软后加蛋煎。
   - 升糖更低、纤维更高，适合控糖人群。

# 龟苓膏

广式经典草本甜品：龟苓膏粉调浆煮熟，冷藏后滑嫩 Q 弹、微苦回甘。
家庭制作全靠现成的龟苓膏粉，10 分钟煮好，配蜂蜜炼乳就是解暑圣品。
成败关键是冷水调浆无颗粒、中小火持续搅拌、凝固期间不移动容器。

## 食材准备与处理

- 龟苓膏粉 25g：推荐老字号品牌（如双钱），粉质和配比稳定。
  传统龟苓膏以龟板、土茯苓为主料，配金银花、罗汉果、凉粉草等熬制。
  家庭用粉已把这些原料浓缩调配好，只需按比例加水即可。
  不同品牌浓度略有差异，水量建议参照包装说明微调。
  参考总水量：每 10g 粉约配 250 毫升水，按此可灵活换算分量。
- 冷水 120 毫升：调浆用，**必须是冷水**。
  热水会让粉瞬间糊化结块，怎么搅都救不回来。
- 开水 500 毫升：冲调煮制用。
- 白砂糖 100g：溶成糖水，平衡龟苓膏的微苦。
  也可减至 60g，吃的时候靠蜂蜜/炼乳补甜。
- 搅拌工具：打蛋器或长筷，调浆和煮制都要用到。
- 模具/容器：小碗、玻璃保鲜盒均可，提前洗净备用。
  分装小份（一人一碗）比整盆凝固更快、取用更方便。

## 详细做法

1. **调粉浆**：锅中倒入龟苓膏粉 25g + 冷水 120 毫升。
   - 动作：充分搅拌至**完全无颗粒**的顺滑稀糊。
   - 判断标准：舀起倒下呈流线，碗底无干粉沉淀。
   - 说明：有颗粒可先静置 2 分钟再搅，或把颗粒压散；顽固颗粒可过筛一次。
2. **溶糖水**：另一个容器中加入白砂糖 100g，倒入沸水 500 毫升。
   - 动作：搅拌至糖完全溶解，杯底无糖粒沉积。
   - 替代：糖也可换成冰片糖，风味更传统、甜感更柔和。
3. **混合**：糖水**缓慢倒入**粉浆中，边倒边快速搅拌。
   - 注意：倒太快或搅太慢会局部糊化结块；立即搅匀是防结块的关键。
4. **煮制**：混合液体放灶上加热。
   - 火候：**中小火**，全程持续搅拌（尤其注意刮锅底和锅边）。
   - 判断标准：液体逐渐变稠、开始冒小泡、搅拌时能看到锅底划痕，约 5-8 分钟。
   - 注意：不要用大火——大火会糊底、结块，还会产生焦苦味盖住草本香。
5. **入模**：达到稠度后立即关火，**快速**倒入模具。
   - 动作要快：膏体降温即开始凝固，锅里磨蹭久了会倒不顺畅、表面不光滑。
6. **静置凝固**：室温自然冷却。
   - 注意：冷却过程中**不可移动、晃动容器**，会破坏正在形成的凝胶网络，导致出水或不成型。
7. **冷藏食用**：冷藏 1-2 小时后口感最佳。
   - 吃法：直接吃、加蜂蜜、淋炼乳，或切块拌入椰奶、水果。

## 关键技巧

1. **冷水调浆是铁律**：龟苓膏粉含淀粉和胶质，遇热水秒结块。
   先在冷水中充分分散，再接触热水，是顺滑无颗粒的唯一途径。
2. **煮制全程搅拌不停**：胶质沉淀锅底只需 1 分钟就会糊。
   刮刀贴着锅底画圈，锅边也要照顾到。
3. **中小火慢煮**：大火外糊内生。
   冒小泡、能划出痕迹的稠度就关火——煮过头水分少，成品会硬、口感像橡皮。
4. **凝固期不碰容器**：凝胶网络在降温时逐渐形成。
   移动、摇晃都会撕裂网络，成品出水、碎裂、不 Q 弹。
5. **微苦是正常的**：龟苓膏的草本苦味来自龟板和土茯苓等原料。
   配蜂蜜、炼乳、椰奶正是为了平衡这份回甘，别因为苦就怀疑失败了。

## 常见问题

1. **浆里全是疙瘩、搅不开**：
   用热水调了粉，或糖水倒入太快没及时搅。
   解决：把浆液过筛一遍再煮；下次严格冷水调浆、慢倒快搅。
2. **冷藏后不凝固、还是稀的**：
   粉水比例不对（水太多），或煮制时间不够、没煮到稠度。
   解决：倒回锅中补 5g 粉调的冷浆重新煮；下次按 25g 粉 : 620ml 总水量执行。
3. **成品出水、碎裂不 Q**：
   冷却过程中移动了容器，或冷藏前没完全凉透就盖盖（冷凝水回流）。
   解决：静置时别碰；彻底放凉再盖盖冷藏。
4. **口感太硬像橡皮**：
   煮过头或水量不足。
   解决：下次冒小泡、刚挂勺就关火；总水量别少于 600 毫升。

## 变化做法

1. **椰奶水果龟苓膏**：龟苓膏切块，倒入椰奶。
   加芒果丁、西瓜丁、蜜豆，是糖水铺的经典搭配，颜值高。
2. **蜂蜜炼乳经典版**：整块淋 1 勺蜂蜜 + 1 勺炼乳。
   最传统的广式吃法，苦甜交融、回甘明显。
3. **咖啡龟苓膏（新式）**：切块后倒入冰拿铁或冷萃咖啡。
   草本苦与咖啡苦意外和谐，是年轻咖啡馆的流行吃法。

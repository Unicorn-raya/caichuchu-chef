# 速冻汤圆

## 食材准备与处理

- **速冻汤圆 1 袋（约 10-15 颗）**：
  - **不需要解冻**，从冷冻室取出直接使用。
  - 解冻会导致表皮吸水变软，煮时极易破裂露馅。
  - 连盒冷冻的汤圆，取出前将盒子在桌上轻敲几下，汤圆会自然脱离包装盒。
  - 表面结霜粘连的，用手轻轻掰开即可，不要泡水。
- **清水（水煮版）1500ml 以上**：
  - 水量至少是汤圆体积的 3 倍，汤圆要有足够活动空间。
- **开水（微波炉版）适量**：
  - 以能完全浸没汤圆为准，约 400-500ml。
- **可选汤底**：
  - 红糖/冰糖 10-20g、姜片 2 片（姜糖水版）。
  - 酒酿 2 勺、枸杞几粒（酒酿汤圆版）。
- **工具**：
  - 水煮版：深锅、汤勺、漏勺。
  - 微波炉版：微波炉可用的大碗（务必深碗，防溢出）。

## 详细做法

### 微波炉快手版（原版流程）

1. **装碗**：
   - 取出速冻汤圆，放入碗中。
2. **加开水**：
   - 倒入开水，直至完全浸没汤圆。
   - **注意先加汤圆再加热水，不要颠倒**：汤圆倒入热水可能溅出烫伤，且无法控制水面高度容易溢出。
3. **微波加热**：
   - 微波炉高火 4 分钟。
   - 碗要深，水面距碗沿至少 3cm，防止沸腾溢出。
4. **检查状态**：
   - 假如汤圆均已吸水膨胀（体积明显变大、浮起、表皮光滑透亮），则已熟。
5. **补时**：
   - 如果没熟，再加热 1 分钟，直到膨胀浮起为止。
6. **取出**：
   - 假如微波炉里碗太烫无法取出，可以用毛巾垫着取，或者某些微波炉可以连托盘一起取出。

### 水煮经典版（更稳妥）

1. **烧水**：
   - 深锅加足量水，大火烧开至完全沸腾。
2. **下汤圆**：
   - 沿着锅边将汤圆一只只"滚"进锅，不要从高处扔（溅水烫伤）。
   - 立即用勺背顺着锅底轻轻推动，防止汤圆粘锅底。
3. **煮到浮起**：
   - 中火保持微沸，煮 3-4 分钟汤圆开始浮起。
   - 全程不要盖严锅盖，避免剧烈沸腾把汤圆撞破。
4. **点水捂熟**：
   - 汤圆浮起后加半碗冷水，改小火"捂"2-3 分钟，使汤圆受热均匀、内外熟透。
5. **判断出锅**：
   - 判断标准：汤圆完全漂浮、表面光滑微微膨胀（体积约 1.5 倍）、皮呈半透明。
   - 全程约 8-10 分钟；煮熟立即用漏勺捞出，久泡会吸水变糊。
6. **连汤盛出**：
   - 碗中先盛适量汤，再舀汤圆连汤放入，避免汤圆之间粘连。

## 关键技巧

1. **不解冻直接煮**：
   - 速冻汤圆表皮糯米层在冷冻下结构完整，解冻后吸水变软，破皮率倍增。
   - 这是所有速冻糯米制品的通用铁律。
2. **先汤圆后开水（微波炉版）**：
   - 颠倒顺序热水会飞溅，且无法准确控制水量。
   - 加水到刚浸没汤圆即可，水太多微波时容易溢出。
3. **浮起后再捂 2 分钟**：
   - 汤圆浮起只说明皮熟了，馅料中心可能还是凉的。
   - 浮起后加冷水小火捂一会儿，馅料才真正热透流心。
4. **微沸不大滚**：
   - 大火狂沸会让汤圆剧烈碰撞摩擦，表皮磨破露馅。
   - 保持水面微微颤动即可，电磁炉建议 800-1000W。
5. **及时捞出**：
   - 煮熟的汤圆在热水里多泡 3 分钟就开始糊化变形。
   - 捞出后如不立即吃，可拌几滴芝麻油防粘。
6. **糯米制品趁热吃、适量吃**：
   - 汤圆冷了质地变硬难消化，老人小孩每次不超过 5-8 颗。

## 常见问题

1. **汤圆破皮露馅、汤变芝麻糊**：
   - 原因：火太大沸腾剧烈、搅动太用力、或汤圆曾解冻复冻有裂纹。
   - 解决：中小火微沸煮；勺背轻推；已破的先捞出，汤里加糖当甜汤喝掉不浪费。
2. **皮熟了馅是凉的**：
   - 原因：水大滚就捞出，没经"捂"的步骤。
   - 解决：浮起后加半碗冷水，小火再煮 2-3 分钟，让热量渗到馅心。
3. **汤圆粘锅底**：
   - 原因：下锅后没及时推动，沉底粘住。
   - 解决：下锅立即勺背轻推；已粘的不要硬铲，水沸后多数会自然浮起脱落。
4. **微波炉版水溢出**：
   - 原因：碗太浅、水太满、功率太高。
   - 解决：用深碗、水面距碗沿 3cm 以上；可在碗下垫个盘子接溢出的水。

## 变化做法

1. **酒酿汤圆**：
   - 汤圆按水煮版煮熟，另一锅烧水加酒酿 3 勺、冰糖 10g、枸杞煮开，冲入汤圆。
   - 酸甜暖胃，江南经典吃法，女性经期也适合（少糖）。
2. **姜糖水汤圆**：
   - 水中加姜片 3 片、红糖 20g 煮 5 分钟出味，再下汤圆按流程煮。
   - 驱寒暖身，冬天或淋雨后首选。
3. **炸汤圆（进阶）**：
   - 汤圆先煮到七分熟捞出沥干，表面裹一层面包糠，160℃ 油温炸 1 分钟至金黄。
   - 外酥里流心，注意汤圆务必沥干，否则下油锅易爆溅。

# 菠萝咖啡特调

## 食材准备与处理

- **咖啡液 40-60ml**：
  - 建议选用花果风味豆：浓缩用中烘豆，冷萃用水洗或日晒豆（埃塞、巴拿马最佳）。
  - 现萃浓缩取 36-40ml（18g 粉萃取），或冷萃液 60ml，务必新鲜。
- **菠萝汁 120-150ml**：
  - 鲜榨菠萝汁最佳；买现成菠萝汁选配料表无额外加糖的。
  - 提前冷藏，低温能抑制菠萝蛋白酶带来的涩麻感。
- **苏打水 50-60ml**：
  - 冰镇原味苏打水/气泡水，提供清爽气泡感。
- **奶盖部分**：
  - 淡奶油 50g + 糖 5-10g，打发至湿性发泡（提起打蛋头有小弯钩、仍能缓慢流动）。
  - 加入朗姆酒 5ml、牛奶 15ml，拌匀成有流动性的奶盖液。
- **海盐一小撮（约 1g）**：
  - 选颗粒细的海盐或玫瑰盐，撒在奶盖表面，放大甜味、中和菠萝涩感。
- **冰块半杯（约 80g）**：
  - 透明矮杯装半杯冰，是分层的前提。

## 详细做法

1. **冰镇杯子**：
   - 透明玻璃杯提前冷藏 10 分钟（可选），取出放入半杯冰块。
2. **组合基底**：
   - 杯中依次倒入咖啡液 40-60ml、菠萝汁 120-150ml、苏打水 50-60ml。
   - 顺序不重要，但每样都沿冰块缓慢倒，减少气泡流失。
   - 轻轻搅拌 1-2 圈让三者混合，液面控制在杯子的 7-8 分满。
3. **打发奶盖**：
   - 淡奶油 50g 加糖 5-10g，电动打蛋器低速打发至湿性发泡。
   - 判断标准：奶盖变浓稠、出现纹路，提起打蛋头尖角下垂弯曲，整体仍可流动。
   - 拌入朗姆酒 5ml 和牛奶 15ml，调至"浓酸奶状"流动性。
4. **倒入奶盖（关键动作）**：
   - 奶盖杯口尽量贴近液面，低高度、缓慢地将奶盖倒在混合液表面。
   - 高度越低越不容易冲破液面，奶盖能均匀漂浮形成完整分层。
   - 也可借助吧勺背面缓冲倒入。
5. **撒海盐**：
   - 在奶盖顶面均匀撒上一小撮海盐（约 1g），不要堆在一处。
6. **完成**：
   - 可插一片鲜菠萝片做装饰。
   - 喝法建议：先直接喝一口奶盖+咖啡的复合层，再搅匀饮用。

## 关键技巧

1. **奶盖只打到湿性发泡**：
   - 打过头的硬性奶盖像奶油蛋糕裱花，倒下去沉底或结块，无法漂浮成层；湿性发泡+牛奶调稀才有"奶盖"的丝滑流动感。
2. **倒奶盖时高度放低**：
   - 重力冲击是分层失败主因；贴面慢倒让奶盖靠浮力铺开，而不是砸进液体里。
3. **菠萝汁必须低温且别太甜**：
   - 菠萝蛋白酶是涩麻感来源，低温+咖啡油脂能抑制它；过甜的菠萝汁会抢掉咖啡风味，变成"糖水"。
4. **海盐是平衡器**：
   - 微量盐能同时放大奶盖甜感、压制菠萝涩感、衔接咖啡苦味，1g 足矣，多了变咸饮。
5. **咖啡和菠萝汁都要新鲜**：
   - 新鲜咖啡液和菠萝汁能大大提升整体风味；隔夜冷萃和开瓶两天的果汁会让整杯变得平庸。

## 常见问题

1. **奶盖沉底混成一团**：
   - 原因：打发过度太硬，或倒的时候高度太高。
   - 解决：湿性发泡即可，倒时贴液面慢倒，或用吧勺引流。
2. **入口发麻发涩**：
   - 原因：菠萝太生、菠萝汁是常温的，蛋白酶活跃。
   - 解决：菠萝汁冷藏后使用；选熟透的菠萝榨汁；盐别省。
3. **只有甜味没有咖啡味**：
   - 原因：菠萝汁比例过高或本身过甜。
   - 解决：咖啡液加到 60ml，菠萝汁减到 120ml，选无糖菠萝汁。
4. **分层不明显**：
   - 原因：冰块太少、液体都是常温，密度差不够。
   - 解决：所有液体提前冰镇，冰块给到半杯，倒每种液体都沿冰块慢倒。

## 变化做法

1. **无酒精版**：
   - 奶盖中去掉朗姆酒，牛奶加到 20ml。
   - 风味略减但更适合白天和开车人群。
2. **菠萝冷萃版**：
   - 基底改为：冷萃咖啡 60ml + 菠萝汁 60ml + 茉莉茶汤 60ml，不加奶盖。
   - 更清爽低卡，突出果香与茶感。
3. **烤菠萝热饮版**：
   - 菠萝片用喷枪或平底锅烤出焦糖边，热咖啡+热菠萝汁+打发热奶泡。
   - 65℃ 加热还能破坏蛋白酶，彻底消除涩麻感，适合冬天。

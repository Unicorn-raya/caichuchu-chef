# 可乐炒饭

## 食材准备与处理

- **米饭 200g（1 人份）**：
  - 隔夜剩饭最佳，水分少、颗粒分明，炒出来不黏坨。
  - 现煮的饭要摊开晾 15 分钟散掉水汽再用。
- **可乐 160ml**：
  - 普通含糖可乐口感最好，焦糖色和甜味都靠它。
  - 无糖可乐也可以，需额外追加 5ml 老抽补色。
- **鸡蛋 3 个**：
  - 2 个用于第一步煎蛋饼，1 个用于最后窝蛋。
  - 嫌麻烦可以第一步直接放 3 个，取消最后窝蛋步骤。
- **火腿肠 20-100g**：
  - 切 5mm 小丁或小片；可用午餐肉、腊肠替代。
- **小葱 1 根**：切葱花，出锅前撒。
- **调味汁（提前混合）**：
  - 生抽 15ml、老抽 7.5ml、蚝油 5ml、豆瓣酱 7.5ml（可选）。
  - 不用豆瓣酱的话老抽追加 5ml。
  - 胡椒粉 1g（白胡椒黑胡椒均可），出锅前用。

## 详细做法

1. **煎蛋饼**：
   - 锅烧热后倒入 25ml 油，中火烧至油面微微冒烟。
   - 打入 2 个鸡蛋，煎至底部完全凝固，约 1 分钟。
   - 翻面再煎至两面完全凝固、边缘微焦。
2. **剪碎**：
   - 关火，将蛋饼取出剪成 2-5cm² 的小块后放回锅中。
   - 也可以不取出，直接用锅铲在锅里铲碎。
3. **加可乐酱汁**：
   - 重新开中火，倒入可乐 160ml、生抽、老抽、豆瓣酱、蚝油。
   - 搅拌均匀，让每块鸡蛋都裹上酱汁。
4. **收汁**：
   - 中火加热，让可乐持续沸腾冒泡。
   - 收到锅内液体只剩约 1/3，约需 3-4 分钟。
   - 判断标准：锅底液体明显变稠、泡沫变大，用铲划开能看到锅底短暂露底。
5. **下饭翻炒**：
   - 倒入米饭和火腿肠丁，转中大火快速翻炒。
   - 把饭团压散，让每粒米都均匀沾上酱汁，炒约 2 分钟。
   - 喜欢干香口感的多炒 1-2 分钟，把水汽炒干。
6. **窝蛋**：
   - 改小火，在锅内食物中心挖一个洞，打入第 3 个鸡蛋。
   - 盖上锅盖，焖 2 分钟。
7. **收尾出锅**：
   - 开盖翻炒至窝蛋熟透并与米饭拌匀。
   - 撒上葱花和胡椒粉，出锅装盘。

## 关键技巧

1. **收汁收到 1/3 再下饭**：
   - 可乐不收浓就下饭，米饭泡水发黏，变成"可乐泡饭"。
   - 收浓后糖分焦糖化，才能炒出焦香微甜的风味。
2. **用剩饭不用热饭**：
   - 热饭含水量高，下锅吸汁后软烂成坨。
   - 剩饭颗粒干爽，能均匀挂汁又粒粒分明。
3. **含糖可乐优于无糖**：
   - 糖是这道菜焦香和亮色的来源，无糖版风味明显打折。
4. **老抽只为上色**：
   - 量要克制，放多了整盘发黑发苦，颜色以琥珀色为佳。
5. **窝蛋增加滑嫩口感**：
   - 最后焖的蛋半熟状态拌入饭中，类似日式蛋拌饭的滑润感，是画龙点睛的一步。

## 常见问题

1. **炒饭湿黏成坨**：
   - 原因：可乐没收到 1/3 就下饭，或用的是热饭。
   - 解决：耐心收汁到浓稠冒大泡；用隔夜剩饭，已经坨了就开大火多炒几分钟烘干。
2. **颜色发暗发黑**：
   - 原因：老抽或豆瓣酱放多了。
   - 解决：老抽严格 7.5ml，宁少勿多。
3. **只有甜味没有咸鲜**：
   - 原因：生抽蚝油比例不够，可乐收得太干。
   - 解决：按比例配好调味汁再下锅；出锅前尝味，淡了补几滴生抽。
4. **蛋煎老了发硬**：
   - 原因：第一步煎蛋火太大、时间太久。
   - 解决：中火煎至刚凝固就翻面，后面还要回锅收汁，不怕不熟。

## 变化做法

1. **葱油可乐炒饭**：
   - 先下一把小葱煎到深绿色捞出，用葱油煎蛋、收汁，出锅前把煎葱拌回。
   - 葱香+可乐焦香，层次更丰富。
2. **可乐鸡翅风味炒饭**：
   - 加 1 勺番茄酱和少许姜片同收，接近可乐鸡翅的味道。
3. **辣味可乐炒饭**：
   - 收汁时加 1 勺老干妈或辣椒粉，甜辣交织，适合重口味。

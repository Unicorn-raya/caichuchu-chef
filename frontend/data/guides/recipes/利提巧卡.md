# 利提巧卡

利提巧卡（Litti Chokha）是印度比哈尔邦的国民美食：利提是包着香料鹰嘴豆粉（Sattu）馅的全麦烤面团，巧卡是烤茄子、土豆、西红柿捣成的香辣蔬菜泥，两者搭配酥油同食。

## 食材准备与处理

- **利提面团**：
  - 全麦面粉 200g、酥油（或食用油）15g、盐 3g、小苏打一小撮（可选）。
  - 温水约 120ml，分次加入，揉成光滑柔软的面团，盖湿布醒 20-30 分钟。
- **利提馅料（Sattu 馅）**：
  - 烤鹰嘴豆粉（Sattu）120g：中国较难买到，可自制——鹰嘴豆干炒至深棕色后磨成粉过筛。
  - 洋葱 1/4 个切碎、青辣椒 1 根切碎、生姜 5g 磨蓉、蒜 2 瓣磨蓉。
  - 孜然籽 3g、芝麻 5g、红辣椒粉 3g、印度黑盐 3g（可用普通盐替代）、盐 3g。
  - 芥末油 15ml（这道菜的灵魂，不建议替换；实在买不到用菜籽油次选）、柠檬汁 10ml、香菜叶切碎。
  - 全部混合均匀，太干捏不成团就淋少许水，馅料应呈松散但可捏合的状态。
- **巧卡（蔬菜泥）**：
  - 茄子 1 个、西红柿 2 个：表面抹一层油，放明火上翻烤至外皮焦黑（约 8-10 分钟），或用烤箱 220°C 烤 25 分钟。
  - 烤好后放凉剥皮，焦皮必须去净。
  - 土豆 2 个：带皮煮 20 分钟至筷子轻松穿透，去皮。
  - 洋葱碎、蒜末、姜蓉、青辣椒碎、香菜碎、柠檬汁、芥末油、盐适量。

## 详细做法

1. **和面**：
   - 全麦面粉加盐、酥油，分次加温水揉成光滑柔软面团。
   - 盖湿布醒 20-30 分钟，醒过的面团延展性好、包馅不易破。
2. **调馅**：
   - 烤鹰嘴豆粉加洋葱碎、青辣椒碎、姜蓉、孜然籽、芝麻、红辣椒粉、黑盐、盐。
   - 加芥末油、柠檬汁、香菜碎，抓匀。
   - 能捏成团不散即可，太干补少许水，太湿补豆粉。
3. **做巧卡**：
   - 烤好剥皮的茄子、西红柿与煮熟的土豆放大碗中。
   - 用叉子捣成粗泥，保留少许颗粒口感更好。
   - 拌入洋葱碎、蒜末、姜蓉、青辣椒碎、香菜、柠檬汁、芥末油和盐，尝味调整。
4. **包利提**：
   - 手上抹酥油，面团分成 6-8 个剂子，搓圆。
   - 用拇指和手指把剂子捏成碗状小窝。
   - 填入 1-2 勺馅料，收口捏紧搓圆，封口务必捏死，否则烤时开裂漏馅。
5. **烤制（三选一）**：
   - **烤箱版**：200°C 预热，烤 20-25 分钟，中途翻面一次，至表面金黄出现焦斑。
   - **平底锅版**：小火盖盖慢烙，勤翻面，约 15 分钟至各面出现焦斑、敲击有空心声。
   - **明火/烤架版**：放烤网上小火翻烤至表面焦黑斑点均匀，最接近传统牛粪火风味。
6. **蘸酥油上桌**：
   - 烤好的利提在融化的酥油里滚一圈，或掰开后浇一勺酥油。
   - 配一大碗巧卡，一口利提一口菜泥同食。

## 关键技巧

1. **Sattu 馅湿度要刚好**：
   - 太干烤出来馅散如沙、噎人；太湿则渗湿面皮、烤后内里皮黏。
   - 标准：抓一把能捏成团、轻碰又能散开。
2. **收口必须捏紧**：
   - 馅是散粉状的，收口有一点缝隙，烤制时会漏粉开裂。
3. **茄子西红柿烤到皮黑**：
   - 只有烤到外皮焦黑，内部才完全软化，并带上标志性的烟熏香，这是巧卡的灵魂。
4. **芥末油不建议替换**：
   - 它提供冲鼻的辛香，是利提巧卡风味的核心标识。
5. **出炉必蘸酥油**：
   - 全麦外壳烤后干硬，蘸酥油才润口香浓，这也是传统吃法。

## 常见问题

1. **利提烤后开裂漏馅**：
   - 原因：收口没捏紧、面皮擀太薄、或馅太湿。
   - 解决：收口反复捏压封死；皮保持 3-4mm 厚；馅调干一点。
2. **外壳硬得咬不动**：
   - 原因：烤过头或没蘸酥油。
   - 解决：烤到金黄焦斑即取出；趁热蘸足酥油回软。
3. **巧卡发苦**：
   - 原因：烤焦的皮没去干净，或茄子没烤透。
   - 解决：焦皮彻底剥净；茄子烤到完全塌软再剥。
4. **馅吃起来干噎**：
   - 原因：Sattu 粉吸水性强，油和柠檬汁不够。
   - 解决：馅料里补足芥末油，吃时利提蘸酥油、配巧卡同食。

## 变化做法

1. **油炸利提（Kachori 式）**：
   - 包好后压扁，160°C 油温炸至金黄，外壳更酥脆，类似油酥点心。
2. **单一蔬菜巧卡**：
   - 只用茄子做 Baingan Chokha，或只用土豆做 Aloo Chokha，风味更纯粹。
3. **Sattu 帕拉塔**：
   - 同样的馅料包入面团后擀平，平底锅烙成 Sattu Paratha，是比哈尔邦经典早餐。

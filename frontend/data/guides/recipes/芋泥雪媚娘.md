# 芋泥雪媚娘

免烤箱的糯叽叽甜品：拉丝糯米皮裹住绵密芋泥和轻盈奶油，一口三重口感。
荔浦芋头的粉糯 + 紫薯粉的淡紫色，颜值和味道都在线，约做 8-10 个。
成败关键是糯米皮趁热揉透反复拉扯、炒好手粉防粘、奶油打硬一点。

## 食材准备与处理

- 荔浦芋头 250-300g：去皮切 2-3 厘米的块。
  荔浦芋头淀粉含量高、口感粉糯，是做芋泥的最佳品种，普通小芋头会偏黏。
  处理：大火蒸/煮 30-40 分钟至筷子一戳就透，全部放入料理机。
- 芋泥馅配比：熟芋头 + 牛奶 30g + 淡奶油 25g + 紫薯粉 3g + 白砂糖 18g。
  紫薯粉主要调色，喜欢颜色深可加至 5-8g；没有可用一小块熟紫薯代替。
- 糯米皮：糯米粉 b 100-120g + 玉米淀粉 22g + 牛奶 135g + 白砂糖 50g。
  玉米淀粉降低黏性、让皮更挺括不易塌，比例不要省。
- 黄油 30g：糯米皮蒸好后趁热揉入，是皮拉丝柔软的关键。
- 手粉：糯米粉 a 30-50g，平底锅**小火炒至微微发黄**。
  生糯米粉有生粉味且不能防粘，必须炒熟；小火慢炒别糊，发黄即离火晾凉。
- 淡奶油 200g + 白砂糖 10-15g（夹心用）：提前冷藏 12 小时以上。
- 工具：料理搅拌机、筛网、不粘手套（必备）。

## 详细做法

1. **打芋泥**：煮熟的芋头放入料理机，加 30g 牛奶、25g 淡奶油打成泥。
   - 再加 3g 紫薯粉、18g 白砂糖，继续搅打至**细腻无颗粒**。
   - 判断标准：舀起呈顺滑膏状；喜欢极致口感可再过一遍筛。
   - 装裱花袋备用；太干可少量多次补牛奶调节。
2. **调糯米糊**：另取大碗，加入糯米粉 b、22g 玉米淀粉、135g 牛奶、50g 白砂糖。
   - 动作：搅匀后**过筛一遍**，去除颗粒，皮才细腻。
3. **蒸糯米皮**：碗上盖保鲜膜，扎几个小洞透气。
   - 火候：中火蒸 25-30 分钟。
   - 判断标准：整体凝固呈半透明果冻状，中心无白色生粉浆。
4. **同步炒手粉**：蒸制期间，把糯米粉 a 放入平底锅。
   - 火候：小火不停翻炒至微微发黄、有熟粉的香味，约 5-8 分钟，盛出晾凉。
5. **揉皮**：蒸好的糯米团趁热加入 30g 黄油。
   - 动作：先用刮刀切拌，不烫手后**戴不粘手套反复揉搓、拉扯折叠 5-10 分钟**。
   - 判断标准：黄油完全吸收，面团光滑、能拉出薄膜、有明显韧性。
   - 说明：拉扯越充分皮越拉丝柔软，这步偷懒皮会粉、会硬。
6. **冷藏**：面团包保鲜膜放冰箱冷藏 1 小时。
   - 原因：冷藏后延展性更好、不粘手，擀皮包馅都不粘。
7. **打发奶油**：淡奶油 200g + 糖 10-15g，打至**硬挺有清晰纹路**。
   - 判断标准：提起打蛋头呈直立小尖角；打软了包的时候会流。
8. **分剂擀皮**：糯米团分成 35-40g 一个的剂子，案板撒熟粉。
   - 动作：擀成直径 10-12 厘米的圆形薄皮，中间略厚边缘薄。
9. **包馅**：糯米皮铺入小碗或雪媚娘模具。
   - 顺序：挤一圈奶油 → 中间挤芋泥馅 → 表面再盖一层奶油。
   - 收口：提起边缘捏紧收口，剪掉多余面皮，收口处抹熟粉防粘。
10. **定型**：倒扣在纸托上，表面筛一层紫薯粉。
    - 冷藏 1-2 小时后口感最佳；制作完即可直接吃，不用再加热。

## 关键技巧

1. **糯米皮必须反复拉扯**：黄油揉进去只是第一步。
   持续拉抻折叠让淀粉网络起韧，皮才能拉丝不破；揉不够的皮一拉就断、口感发粉。
2. **全程戴不粘手套操作**：糯米团黏性极强。
   徒手或普通一次性手套会粘到怀疑人生，PVC 不粘手套是标配。
3. **手粉必须炒熟**：生粉防粘效果差且有生味。
   炒到微黄立即离火，炒糊会发苦。
4. **奶油打硬一点**：软奶油支撑不住形状。
   包的时候会从收口流出，成品塌扁不饱满。
5. **皮中间厚边缘薄**：擀皮时中间留厚度。
   底部承重不易破，边缘薄收口后不会有厚重的面疙瘩。
6. **冷藏后再吃**：刚包好皮偏软塌。
   冷藏 1-2 小时皮会变挺括，奶油定型，切面漂亮。

## 常见问题

1. **皮太粘、没法操作**：
   拉扯不够、没冷藏，或手粉用少了。
   解决：面团冷藏 1 小时再包；案板和手上随时补熟粉。
2. **皮发硬、不拉丝**：
   蒸好后揉拉时间太短，或冷藏过夜淀粉老化。
   解决：揉够 5-10 分钟；最好当天吃完，隔夜可室温回软半小时再吃。
3. **芋泥太稀、包不住**：
   牛奶/淡奶油一次加多了。
   解决：倒入不粘锅小火翻炒 3-5 分钟收干水分，放凉再用。
4. **包的时候皮破了**：
   皮擀太薄或馅放太多。
   解决：皮保持中间厚；馅料减 1/3；破口处补一小片皮捏合抹粉。

## 变化做法

1. **芋泥乳酪版**：夹心换成"奶油 + 芋泥 + 奶酪酱"。
   奶油奶酪 200g + 糖 20g 打顺滑装裱花袋，挤在芋泥上再盖奶油，奶香更浓。
2. **芒果/草莓雪媚娘**：芋泥换成新鲜水果块。
   奶油 + 整块芒果是经典原味款，水分大的水果要先用厨房纸吸干。
3. **冷冻冰淇淋版**：包好后冷冻 2 小时再吃。
   糯米皮冷冻后依然软糯，内馅呈冰淇淋口感，是夏天的隐藏吃法。

# 草莓冰淇淋

免冰淇淋机的草莓冰淇淋：打发淡奶油 + 炼乳做基底，拌入自熬草莓糖浆。
一半草莓熬成糖浆出风味，一半鲜草莓留颗粒，成品绵密带果肉、无冰渣。
成败关键是淡奶油打发到位、糖浆熬到挂线、冷冻前充分混合。

## 食材准备与处理

- 新鲜草莓 400-500g：洗净去蒂，切成 5mm 见方的小块。
  分两份：一半熬糖浆，一半**保留鲜果粒**最后拌入，口感才有层次。
  熟透的草莓甜度高、香味足，熬糖浆效果最好。
- 白砂糖 60-80g：熬糖浆用，按草莓甜度调整。
- 加糖炼乳 200g：提供甜度和顺滑质地，是免蛋基底的灵魂。
  不建议再额外加糖进基底，糖过多会析出冰晶。
- 重奶油/淡奶油 480ml（乳脂 35% 以上）：**提前冷藏 12 小时以上**。
  打发盆和打蛋头也提前冷冻 15 分钟，低温是打发稳定的前提。
- 香草精 1 小勺（约 5 毫升）：分两处用，糖浆和基底各一半。
- 盐一小撮（约 1g）：激发甜味、平衡腻感，吃不出咸味。
- 草莓糖浆（可选）：成品淋面装饰用。

## 详细做法

1. **熬草莓糖浆**：一半草莓丁 + 白砂糖放入酱汁锅。
   - 火候：中火加热，边加热边搅拌。
   - 过程：草莓受热出汁，逐渐形成糖浆；继续煮到草莓软烂变形、糖浆稍稠。
   - 判断标准：用刮刀划过锅底，糖浆**分开后保持 3 秒不愈合**即可。
   - 离火后加入半份香草精和一小撮盐，搅匀，彻底放凉。
2. **打发基底**：大碗中加入炼乳、淡奶油、剩余香草精和盐。
   - 动作：用打蛋器打发，中速打到**轻盈蓬松、出现柔软尖峰**（软尖角，约六七分发）。
   - 判断标准：提起打蛋头有弯钩状软峰，画八字纹路缓慢消失。
   - 注意：不要打到硬性发泡，打过头会油水分离，成品有黄油颗粒感。
3. **拌入鲜果粒**：把保留的新鲜草莓丁**折叠拌入**基底。
   - 手法：用刮刀从底部翻拌，轻柔均匀，保住打进去的空气。
4. **入模**：混合物倒入可冷冻的密封容器（约 1.5L），表面抹平。
5. **旋入糖浆**：放凉的草莓糖浆淋在表面。
   - 动作：用筷子或刮刀**轻轻划圈 2-3 下**，形成大理石纹路。
   - 注意：不要搅匀，过度混合就吃不到糖浆的风味层次了。
6. **冷冻**：盖盖密封，冷冻至少 6 小时，最好过夜。
   - 判断标准：整体冻硬，勺子能挖出成型的球。
7. **食用**：取出后室温放 5 分钟回软。
   - 挖球勺先用热水烫一下擦干，挖出的球圆润不粘。

## 关键技巧

1. **淡奶油必须充分冷藏**：至少冷藏 12 小时，盆和打蛋头也要冷。
   温度高的淡奶油打不发或打发了也很快塌陷，还会油水分离。
2. **只打到软尖峰**：六七分发的奶油冻后口感绵密。
   打到硬峰再冷冻，口感会发干发渣，甚至吃出黄油粒。
3. **糖浆必须熬到"挂线"**：划开保持 3 秒是浓缩到位的标志。
   太稀的糖浆水分多，是冰渣的主要来源。
4. **一半鲜果一半糖浆**：鲜果保口感、糖浆保风味。
   全部熬糖浆就没有果肉惊喜，全部用鲜果则香味寡淡还易出冰渣。
5. **冷冻防冰渣**：容器贴一层保鲜膜再盖盖，隔绝空气防串味。
   讲究的可冷冻 2 小时后取出搅拌一次再冻，重复 2 次，冰晶更细。
6. **一周内吃完**：自制冰淇淋无稳定剂。
   放太久奶香流失、冰渣变多，口感大打折扣。

## 常见问题

1. **成品有冰渣、不绵密**：
   淡奶油打发不足、糖浆太稀，或容器密封不好。
   解决：打到软尖峰；糖浆熬到挂线；冷冻时表面贴保鲜膜。
2. **油水分离、有黄油颗粒**：
   淡奶油打发过度。
   解决：基底打软峰即停；如果已分离，可小火加热融化后彻底放凉，重新打发补救。
3. **冻得挖不动**：
   炼乳比例偏低、冻太久，属正常物理现象。
   解决：室温回温 5-10 分钟再挖；挖球勺烫热水。
4. **草莓味淡**：
   草莓不够熟，或糖浆熬的时间不够、风味没浓缩。
   解决：选熟透草莓；糖浆熬到浓稠挂线；可加 1 小勺柠檬汁提味。

## 变化做法

1. **芒果/蓝莓版**：等量替换水果，熬糖浆的步骤相同。
   芒果泥不用留颗粒，全部打泥拌入，口感最绵密。
2. **奥利奥草莓版**：基底中拌入 80g 奥利奥碎（去夹心）。
   与草莓糖浆是绝配，颜值口感双升级。
3. **冻水果快手版（免打发）**：
   冻草莓 300g + 冻香蕉 1 根 + 冻酸奶 150g，料理机搅打 2 分钟。
   立等可取，无需冷冻等待，口感接近雪芭。

# 带把肘子

## 食材准备与处理

**主料：**

- 带脚猪前肘 1 只（约 1250g）：必须选前肘——肉质紧实、瘦肉多、皮薄，且必须"带把"（连脚爪），这是这道菜名字的由来。让摊主烧净毛茬，回家再用刀刮洗两遍。

**整形剔骨（本菜最见功夫的一步）：**

1. 肘子头朝外、肘把（脚爪）朝里、肘皮朝下放在案板上。
2. 用刀在正中由肘头向肘把，沿着腿骨将皮剖开。
3. 剔去腿骨两边的肉（三面离肉），但底部骨与肉保持相连，让骨头完整露出。
4. 将两节腿骨从中间用刀背砸断（家里的刀背不行就用小斧头，垫着砧板操作，注意安全）——骨头断而皮肉相连，蒸好后腿骨犹如"把柄"。

**调料与香料：**

- 八角 3g、桂皮 5g、精盐 10g。
- 红豆腐乳 15g、甜面酱 50-100g、红酱油（老抽）30ml、白酱油（生抽）25ml、料酒 15ml。
- 葱 75g（部分切段、部分切葱花）、姜 10g 切片、蒜 20g 切片。
- 消毒纱布 1 块（开水煮 5 分钟消毒）。
- 上桌配碟：葱段、甜面酱各 1 小碟。

**背景知识：**

- 带把肘子是陕西大荔（古同州）传统名菜，秦菜代表，成菜色泽枣红、形如蒲团、腿骨如把柄，故称"带把"。
- 传统上是州府衙门和民间喜宴的压轴硬菜，2018 年被评为"中国菜"之陕西十大经典名菜。

## 详细做法

1. 煮制定型：处理好的肘子放入煮锅，加冷水没过，大火烧开撇净浮沫，转中火煮至七成熟（约 30-40 分钟）——外观正常、切开内部呈淡红色。捞出用干净抹布彻底擦干水分。

2. 抹皮上色：趁热用红酱油均匀涂抹肉皮，多抹两遍。热肘子毛孔张开，酱油才能吃进去，蒸出来皮色枣红。此步决定成品颜色，不可省略。

3. 铺底料：取蒸盆（或大碗）一个，盆底放入八角、桂皮。

4. 装盘定型：先将肘把的关节处用手掰断（不伤外皮），再将肘皮朝下装进蒸盆；根据肘子体型，将肘把贴住盆边窝着装进盆内，团成圆形，骨头朝上如把柄。

5. 盖纱布：撒入精盐，用消毒纱布盖在肉上，四周压实贴住肉面。

6. 抹酱料：将甜面酱、葱段、红豆腐乳（压碎）、红酱油、白酱油、姜片、蒜片、料酒，均匀抹在纱布上面。纱布隔开酱料与肉，既入味又保证成品表皮完整干净。

7. 旺火蒸制：蒸锅加足水（一次性加够，中途加水必须加开水），大火上汽后放入蒸盆，保持旺火蒸约 3 小时，以蒸烂为准。判断标准：筷子插入瘦肉如插豆腐，轻提骨头能骨肉分离。笼盖留一条小缝，防止蒸汽过大损坏形态和色泽。

8. 扣盘：蒸好取出，揭去纱布，拣去八角、桂皮，将盘子扣在蒸盆上迅速翻扣过来，肘子圆整如蒲团、色泽枣红。

9. 上桌：另带葱段和甜面酱小碟；也可先将甜面酱抹在肘面上，再配葱段碟。吃法是抹酱、就葱，肥而不腻。

## 关键技巧

1. 选前肘、必带把：前肘皮薄瘦肉多、不易散烂；后肘肥腻且形态不佳。"带把"是这道菜的标志，无把不成菜。

2. 断骨不断皮：砸断腿骨时宁可多垫几层布护住皮面，肘皮必须完整无缺，否则蒸出来卖相全毁。

3. 七成熟就出锅：煮到七成熟（内部淡红）即可，煮太烂蒸完肉散无形；太生则蒸不透。没把握就请教家中长辈或多煮 5 分钟。

4. 趁热抹酱油：凉肘子抹不上色。擦得越干、抹得越热，皮色越枣红漂亮。

5. 旺火足汽 3 小时：中途千万别断火断汽，蒸锅水要一次加足；笼盖留缝防汽水回落。酥烂程度全靠蒸功，高压锅代替不了这个口感。

## 常见问题

1. 蒸出来颜色发白不上色？抹酱油时肘子凉了，或没擦干水。务必趁热、擦干、多抹两遍红酱油。

2. 肘子散了不成形？煮过头了，或装盆时没窝紧。煮到七成熟即停，装盆时贴盆边窝成圆形。

3. 肉蒸不烂、咬不动？火太小或时间不够。必须旺火足汽蒸满 3 小时，以"烂"为唯一标准。

4. 表皮起泡破损？笼盖没留缝，蒸汽太猛冲击皮面。蒸时笼盖留一小缝隙。

5. 酱料味道没进去？纱布与肉没贴实，或酱料抹得太薄。纱布压实，酱料厚厚抹匀一层。

## 变化做法

1. 家常简化版：用去骨肘子或不带脚的前肘，省去剔骨砸骨步骤，其余流程不变，风味近似但少了"把"。

2. 高压锅速成版：抹好酱料后高压锅上汽压 40 分钟，再倒回炒锅大火收汁。口感偏软糯，少了蒸制的酥烂层次，但省时。

3. 冰糖红亮版：蒸制时加 15g 冰糖同蒸，成品色泽更红亮、口味带微甜，接近官府菜风格。

4. 荷香版：蒸盆底部垫一张干荷叶，成品带淡淡荷香，解腻清爽。

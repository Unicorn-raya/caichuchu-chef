# 红柚蛋糕

免烤箱的锡纸盘小蛋糕：鸡蛋 + 面粉 + 红柚果肉搅匀成糊，蒸/烤皆可。
红柚果肉带来清新的微酸和颗粒感，颜色粉嫩，是秋冬柚子季的快手甜点。
成败关键是果肉别贪多、面糊搅到无疙瘩、模具先刷油防粘。

## 食材准备与处理

- 红柚果肉 20-40g：剥去外皮、内皮和籽，只留果肉颗粒。
  内皮（白色筋膜）发苦，务必撕干净，否则蛋糕会带苦味。
  处理：果肉轻轻拆散成小粒，太大的块会沉底，分布不均。
  用量注意：每份**不要超过 40g**，果肉太多会出水、影响成型和观感。
- 鸡蛋 2 个：直接打入锡纸盘中即可，无需分离。
- 面粉 80g（分两次加入，每次 40g）：普通中筋或低筋面粉均可。
  分两次加更容易搅匀、不起面疙瘩。
- 白砂糖 15g（分两次加入，10g + 5g）：微甜口味。
  喜欢甜的可再加 10g；红柚本身酸甜，糖不必太多。
- 食用油 15ml：无味油（玉米油、葵花籽油）最佳。
  黄油或花生油香味太重，会盖住红柚的清香。
- 水 80ml（分两次加入，每次 40ml）：调节面糊稀稠度。
- 锡纸盘 1-2 个：一次性锡纸盘导热快、免洗脱模方便。

## 详细做法

1. **打蛋入盘**：锡纸盘中打入 2 个鸡蛋，加入 20g 红柚果肉。
   - 动作：用筷子把鸡蛋打散、与果肉混匀。
2. **刷油防粘**：倒入 15ml 食用油。
   - 动作：端起锡纸盘**轻轻摇晃**，让油均匀覆盖盘底和四壁。
   - 原因：油膜是脱模不粘的关键，角落也别漏。
3. **加第一批料**：放入 10g 糖、40g 面粉和 40ml 水。
   - 动作：用筷子**顺时针方向持续搅拌**。
   - 判断标准：搅成淡黄色糊状，看不见干面粉和明显疙瘩。
4. **加第二批料**：再放入 5g 糖、40g 面粉和 40ml 水。
   - 动作：继续同方向搅拌。
   - 判断标准：面糊整体颜色均匀、无面粉疙瘩、能缓慢流动（浓稠酸奶状）。
   - 说明："糊状"指没有疙瘩且整体均匀；太稀可补 5g 面粉，太稠补 5ml 水。
5. **蒸制（推荐）**：蒸锅水烧开后放入锡纸盘。
   - 火候：中火保持蒸汽充足，蒸 15-20 分钟。
   - 判断标准：牙签插入中心，拔出**不粘湿面糊**即为熟透。
6. **或用烤箱/空气炸锅**：
   - 温度：170-180℃，烤 15-20 分钟。
   - 判断标准：表面微黄、按压回弹、牙签测试无粘连。
7. **出炉取盘**：刚出锅的锡纸盘非常烫。
   - 动作：用夹子夹取，或用湿抹布等隔热材料拿取，不要徒手拿。
   - 稍晾 2-3 分钟后即可用勺子挖食，或倒扣脱模切块。

## 关键技巧

1. **红柚果肉宁少勿多**：果肉超过 40g 会大量出水。
   蛋糕内部湿黏难熟，外观也会坑洼难看；20g 点缀效果最佳。
2. **内皮务必撕干净**：红柚白色筋膜含柚皮苷，味道极苦。
   残留的籽和内皮是成品发苦的唯一原因。
3. **面糊分两次调**：一次倒完全部面粉很难搅匀。
   分次加料每批都搅到顺滑，是"无疙瘩"的稳妥做法。
4. **模具先晃匀油**：油膜不完整就会局部粘底。
   摇晃比刷子更均匀，别忘了盘壁也要挂到油。
5. **牙签测试判断熟度**：不同火力和盘深时间差异大。
   以"插入中心拔出干净"为准，别只掐时间。

## 常见问题

1. **蛋糕发苦**：
   红柚的白色内皮或籽没剥干净。
   解决：只取纯果肉粒，筋膜一丝不留；下次可换更甜的三红蜜柚。
2. **内部湿黏、像没熟**：
   果肉放太多出水，或蒸制时间不足。
   解决：果肉控制在 20-40g；回锅中火再蒸 5 分钟，牙签复测。
3. **面糊有面粉疙瘩**：
   面粉一次全倒入、搅拌不够。
   解决：分次加料；已有疙瘩可用筷子压散，或将面糊过一遍筛。
4. **脱模时粘底、不完整**：
   油没覆盖均匀，或太烫时急着倒扣。
   解决：油要晃满盘底四壁；稍晾 3 分钟再脱模，用小勺沿边划一圈辅助。

## 变化做法

1. **红柚戚风版（烤箱）**：
   3 蛋分蛋打发，蛋黄糊中加入 55g 柚果汁，果粒拌少许干粉防沉底。
   上下火 145℃ 烤 60 分钟，倒扣晾凉，口感像云朵般轻盈。
2. **红柚奶油蛋糕（装饰版）**：
   戚风胚切三片，夹层抹打发淡奶油、铺满红柚果肉碎。
   表面果肉奶油随意封胚再撒果粒，无需抹面技巧，颜值高。
3. **红柚千层糕（蒸制）**：
   红柚榨汁加钵仔糕粉调浆，与椰浆白浆交替倒入碗中。
   每层大火蒸 3 分钟，层层叠加，放凉后切块，Q 弹爽滑。

# 反沙芋头

潮汕传统名点：炸得粉糯的芋头条裹上熬到恰好的糖浆，离火翻炒至糖霜凝结。
外裹白雪般的"沙"，内里是粉糯芋香。成败全在熬糖的火候与关火翻炒的时机。

## 食材准备与处理

- 荔浦芋头 半个（约 300-500g）：去皮后切**长条，稍粗一些**。
  刀法：约 1.5-2 厘米见方、5 厘米长的条；切太细翻炒时容易断烂。
  粗细尽量一致，保证炸制时熟度均匀。
  荔浦芋头淀粉含量高、口感粉糯，是反沙的最佳品种。
- 白砂糖 30-60g（或冰糖）：与水的比例严格 **2:1**。
  糖量可按芋头量等比放大：300g 芋头配 60g 糖 + 30g 水是常见配比。
- 水 15-30 毫升：只用于化糖，量不能多。
  水多了熬制时间长，糖浆火候难以判断。
- 葱 1 根：切葱花，起锅前增香。
  葱花是传统反沙芋头的标志性搭配，不建议省略。
- 食用油：炸制用，量以能没过芋头为准。

## 详细做法

1. **切条**：芋头去皮切成长条，稍微大条一点，翻炒过程不容易烂。
   - 注意：切好后**不要泡水**——芋头表面淀粉有助于炸出干爽外壳。
2. **热油试温**：锅中倒入能没过芋头的油。
   - 火候：中火烧至**五六成热**（约 150-160℃）。
   - 判断标准：插入筷子，周围冒出细密小泡即可。
3. **炸芋头**：下芋头条炸制。
   - 火候：转中小火。
   - 时间：8-10 分钟，期间不时翻动让受热均匀。
   - 判断标准：**芋头浮起、表面微微泛黄、用筷子能轻松戳穿**即捞出沥油。
   - 注意：不要炸到深黄，外焦内干会影响粉糯口感。
4. **留油备用**：炸芋头的油倒出留着，后面炒菜可以用，别浪费。
   - 注意：锅洗净擦干（或另取一口干净锅），**不能留油**。
   - 原因：锅里有残油，糖浆挂不住，会"油糖分离"不起沙。
5. **熬糖浆（关键步骤）**：锅中倒入糖 30g + 水 15g（2:1）。
   - 火候：中小火加热，期间轻轻搅动帮助融化。
   - 观察：先是大而稀的泡 → 水分渐少 → 转为**密集的小鱼眼泡**。
   - 判断标准：糖浆不变色（或极轻微一点黄）——这就是 100-130℃ 的"反沙温度区间"。
6. **下芋头翻炒**：倒入葱花和炸好的芋头，**关火**。
   - 动作：快速翻炒，让每根芋头均匀裹上糖浆。
7. **起沙出锅**：持续翻炒，随着温度下降，糖浆在芋头表面重新结晶变白——这就是"反沙"。
   - 技巧：有条件的可用风扇对着锅吹，加速降温，白霜出现得更快更均匀。
   - 判断标准：糖霜挂满每根芋头，立即装盘。

## 关键技巧

1. **糖水比严格 2:1，火候看泡不看表**：大泡转小泡（鱼眼泡）、糖浆仍透明是最佳下锅点。
   熬不够——糖浆稀，挂上后不干爽，变"拔丝"。
   熬过头——颜色变深发黄，直接进入拔丝/焦糖区间，反不出沙。
2. **反沙温度 100-130℃，拔丝 170-190℃**：两个区间只差一点时间。
   大泡变小泡的过程非常快，看到小泡密集出现**立刻离火下芋头**，犹豫几秒就可能前功尽弃。
3. **关火翻炒是起沙的原理**：反沙的本质是过饱和糖浆降温后重新结晶。
   关火 + 快速翻炒（甚至扇风降温）让糖浆在芋头表面均匀凝出白色糖霜。
   不关火继续加热，糖永远不会结晶。
4. **锅要干净无油**：熬糖的锅里若有残油，糖浆乳化后无法结晶。
   只能得到亮晶晶的糖衣，而不是白霜。
5. **芋头条切粗一点**：翻炒过程中芋头条彼此碰撞。
   细条容易断、棱角容易掉渣，粗条成品完整、截面粉糯。
6. **趁热吃**：刚出锅的反沙芋头外脆内粉。
   放久后糖霜吸潮会化，口感大打折扣；注意刚做好的很烫，小心烫嘴。

## 常见问题

1. **不出沙、变成拔丝**：
   糖浆熬过头（已发黄）或熬不够（太稀），或翻炒时没关火。
   解决：记住"鱼眼泡、不变色、即离火"；失败了的拔丝芋头也能吃，下次提前 10 秒离火。
2. **糖霜发黄发苦**：
   熬制后期火太大，或搅动太勤导致局部焦化。
   解决：全程中小火，后期轻推锅底即可。
3. **芋头外糊内生**：
   油温过高下锅，表皮焦了中心还生。
   解决：筷子试温冒小泡（五六成热）再下，中小火慢炸到能轻松戳穿。
4. **糖挂不上、锅底剩糖浆**：
   锅里有残油，或芋头炸完表面太油。
   解决：炸好的芋头先在厨房纸上滚一下吸走表面油，再下锅裹糖。

## 变化做法

1. **反沙番薯（金银双色）**：
   同样的方法处理红薯条。
   潮汕常把反沙芋头和反沙番薯拼一盘，金银两色，雅称"金柱银柱"。
2. **先蒸后炸版**：
   芋头条先蒸 15 分钟至熟，冷却后再下油锅炸到表面微黄。
   用油少、外壳薄脆，适合怕油腻的家庭做法。
3. **橙皮/芝麻增香版**：
   糖浆快好时加入少许橙皮屑或熟白芝麻一起裹。
   香气更丰富，是潮汕宴席上的常见变化。

# 金针菇汤

## 食材准备与处理

- **金针菇 1 把（约 200g）**：
  - 切去根部相连的老蒂 1-2cm，用手把金针菇徒手掰散，越散越好。
  - 掰不散的整捆下锅，缝隙里容易藏杂质，吃起来还容易塞牙。
  - 放入清水中淘洗两遍，轻轻攥干水分。
  - 切成 3-5cm 长的小段，长度不宜超过 5cm，太长不好入口。
- **鸡蛋 1-2 个（可选）**：
  - 打入碗中充分搅散，喜欢蛋花汤的就加，清汤版可不放。
- **小葱 1 根**：切葱花，出锅前撒。
- **调味**：盐、味精（或鸡精）、白胡椒粉少许、香油 3-4 滴。
- **可选**：
  - 火腿肠切柳叶片、嫩豆腐丁、菠菜段，按喜好添加。
  - 水淀粉 1 勺（喜欢微稠羹状口感时勾芡用）。
- **选购要点**：
  - 选菇体洁白、菇帽紧实未开伞的金针菇，发黄发黏的不新鲜。
  - 袋装金针菇根蒂处常带培养基碎屑，切除根蒂后务必淘洗干净。

## 详细做法

1. **烧水**：
   - 锅中加入约 800ml 清水（水量约为食材高度的 1.1 倍），大火烧开。
   - 关键是水烧开再下金针菇，冷水同煮容易出黏液、汤发浑。
2. **下金针菇**：
   - 水大开后放入金针菇段，用筷子拨散。
   - 保持中火，水再次沸腾后煮 3 分钟。
   - 判断标准：金针菇由雪白转为微微透明、质地变软塌。
3. **可选焯水版（更稳妥）**：
   - 肠胃敏感者可先用另一锅开水焯 1-2 分钟捞出，再重新烧水入汤。
   - 焯水能进一步降低秋水仙碱含量，减少肠胃刺激。
4. **调味**：
   - 加入盐 3g、味精少许，搅拌均匀。
   - 喜欢微稠口感的此时淋入水淀粉，边倒边搅至汤略微挂勺。
5. **淋蛋花（可选）**：
   - 保持汤面微沸，左手持碗将蛋液徐徐转圈淋入。
   - 右手拿筷子在锅中顺时针快速搅动，蛋花会又细又匀。
   - 蛋花凝固浮起即可，约 15-20 秒。
6. **收尾出锅**：
   - 继续加热约 30 秒让味道融合，关火。
   - 撒入白胡椒粉少许、葱花，滴入 3-4 滴香油（或麻油）增香，盛碗上桌。

## 关键技巧

1. **金针菇必须煮熟煮透**：
   - 金针菇含秋水仙碱，未熟透食用可能刺激肠胃、引起腹痛腹泻。
   - 水开后至少煮 3 分钟，宁多勿少。
2. **水开再下菇**：
   - 冷水下金针菇会煮出黏液，汤发浑发滑，口感差。
3. **徒手掰散再切**：
   - 整捆的金针菇缝隙藏泥沙，掰散后清洗才干净，入口也不塞牙。
4. **蛋花要"淋+搅"配合**：
   - 一手缓慢淋蛋液、一手快速搅动，蛋花细碎均匀。
   - 倒入后不搅会结成大块，卖相和口感都差。
5. **香油最后滴**：
   - 香油遇高温香气挥发快，关火后再滴才能保留香味。

## 常见问题

1. **吃完肠胃不适**：
   - 原因：金针菇没煮熟，秋水仙碱未破坏。
   - 解决：务必水开后煮满 3 分钟，肠胃弱者先焯水再煮汤。
2. **汤发浑、口感发黏**：
   - 原因：冷水下菇或久煮过度，金针菇黏液析出。
   - 解决：水开下锅、煮 3 分钟即调味出锅，不要久炖。
3. **蛋花成一坨**：
   - 原因：蛋液一次倒入且没搅动。
   - 解决：细线慢淋、另一手同步快速搅汤。
4. **金针菇塞牙难嚼**：
   - 原因：段切得太长或没掰散。
   - 解决：切段控制在 5cm 以内，下锅前充分抖散。

## 变化做法

1. **金针菇火腿蛋花汤**：
   - 加火腿肠柳叶片与金针菇同煮，汤味更鲜，颜色更好看。
2. **金针菇豆腐羹**：
   - 加嫩豆腐丁，勾薄芡，撒香菜，口感滑嫩似羹。
3. **酸辣金针菇汤**：
   - 出锅前加 1 勺香醋、半勺辣椒油和白胡椒粉，开胃解腻。

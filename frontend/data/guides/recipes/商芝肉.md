# 商芝肉

## 食材准备与处理

**主料：**

- 带皮猪五花肉 500g：选五花三层、肥瘦相间的精五花，刮洗干净，剔除过厚的瘦肉，改成便于切片的方块。
- 商芝（干蕨菜）50g：商洛秦岭特产。买不到可用其他蕨菜干、梅干菜或黄花菜替代。

**辅料：**

- 葱 10g（5g 切段、5g 切斜片）、姜 5g（切片与切末分用）、八角 3 颗。
- 摊鸡蛋皮 15g：鸡蛋 1 个打散，小火摊成薄蛋皮，切成 2.4-3cm 长的象眼（三角）片。
- 鸡汤 200g（没有可用清水加鸡精替代）、熟猪油适量、芝麻油少许。

**调味：**

- 蜂蜜 15g、醋 5g（涂肉皮用）；酱油 10g、料酒 15g、精盐 2.5g、味精 1.5g。

**商芝预处理：**

- 商芝入沸水锅中煮软捞出，摘除老茎和杂质，淘洗干净，切成 3cm 长的段。
- 加酱油 5g、精盐 1g、熟猪油 10g 拌匀，腌入底味备用。

**五花肉预处理：**

1. 煮肉：肉块入煮锅，加足量水，煮至六成熟（肉色变白、约 20 分钟），捞出。
2. 涂皮：趁热用蜂蜜和醋均匀涂抹肉皮——蜂蜜上色、醋让皮炸后起泡疏松。
3. 炸皮：炒锅放熟猪油，旺火烧至八成热（约 200℃，油面平静冒青烟），肉块皮朝下投入，炸至金红色虎皮状。
4. 泡软：炸好的肉立刻捞入之前煮肉的凉汤中浸泡，待表皮泡软起皱。

## 详细做法

1. 切片装碗：泡软的肉块捞出，切成 10cm 长、0.6-0.7cm 厚的大片，皮朝下整齐码入蒸碗底部（码放直接影响扣出来的品相）。

2. 铺商芝：腌好的商芝段均匀盖在肉片上。

3. 浇汁：鸡汤 100g 加酱油 5g、精盐 0.5g、料酒 15g 搅匀，浇入蒸碗；放上姜片、葱段、八角。

4. 蒸制：上笼，旺火蒸约 30 分钟，转小火继续蒸约 1 小时 30 分钟，蒸至肉质熟烂。蒸的时间宁长勿短，成菜才软糯到入口即化。

5. 扣盘：取出蒸碗，拣去姜片、葱段、八角，将原汁滗出留用；用汤盘盖住碗口，快速翻转扣入盘中（动作快、准，小心烫）。

6. 浇汁收尾：炒锅放入鸡汤 100g 和滗出的原汁，旺火烧沸，下姜末、葱斜片、味精搅匀，投入蛋皮象眼片，淋芝麻油，趁热浇在扣好的肉上即成。

## 关键技巧

1. 肉必须带皮：五花三层带皮是这道菜的根基，去皮就失去了虎皮软糯的口感和红润的卖相。

2. 蜂蜜+醋涂皮：趁热涂抹，炸后皮色金红、起泡疏松如虎皮，这是扣肉类菜品卖相的通用秘诀（梅菜扣肉同理）。

3. 炸后泡回软：炸好的肉立刻泡入凉肉汤，热胀冷缩让表皮起皱回软，切片整齐不碎。

4. 蒸制宁长勿短：旺火半小时 + 小火一个半小时是底线，蒸透的五花肉油脂尽出、入口即化；时间不够则肥腻发韧。

5. 可先蒸好备用：这道菜适合提前蒸好，临上桌前复蒸 15 分钟、现浇热汁，宴客时节奏从容。

6. 商芝吸油是本分：商芝（蕨菜）纤维粗、吸油性强，正好承接五花肉蒸出的油脂，肉不腻、菜更香，二者是互相成就的搭配。

## 常见问题

1. 肉皮不起虎皮、颜色发白？蜂蜜醋没涂或油温不够。涂匀后油温必须八成热再下锅，皮朝下炸到位。

2. 切片散碎？没泡软就切，或煮得太烂。炸后务必泡回软；煮到六成熟即可，后序还有炸和蒸。

3. 商芝发柴有渣？老茎杂质没去净，或没提前煮软。干蕨菜必须沸水煮软、摘净老茎、反复淘洗。

4. 吃着肥腻？蒸制时间不足。油脂全靠长时间蒸制逼出并被商芝吸收，小火一个半小时不能打折。

5. 扣盘散形、卖相差？肉片码放不整齐或翻扣犹豫。码碗时片片紧贴，扣盘前确认碗盘贴合，一次性快速翻转。

## 变化做法

1. 梅菜扣肉：商芝换成惠州梅干菜（提前泡软炒香），调味加糖和南乳，是客家经典，也是商芝肉最广为人知的"亲戚"。

2. 商芝肉加黄花菜大枣：商洛当地宴席做法，蒸碗时加泡发的黄花菜、油炸豆腐条和大枣同蒸，荤素搭配更丰盛。

3. 家常简化版：省去摊蛋皮和浇汁步骤，蒸好扣盘后直接淋一勺加热的蒸肉原汁，风味保留八九成。

4. 芋头扣肉（同工艺）：商芝换成炸过的荔浦芋头片，与肉片相间码碗同蒸，芋头吸油粉糯，是广西版"扣肉"。

# 鲜肉烧卖

## 食材准备与处理

- **烧卖皮 20-25 张（市售）**：
  - 直径 8-10cm、每张约 10-15g；没有可用大馄饨皮，或饺子皮再擀薄一圈。
  - 皮和馅的比例控制在 1:2-1:2.5，即每张皮包 25-30g 馅。
- **猪肉末 300g**：
  - 肥瘦比 3:7（前腿或梅花肉），太瘦柴、太肥腻。
  - 绞肉用中档，保持适中颗粒感，肉馅太细像糊、太粗发散。
- **调味（基础版）**：
  - 姜末 5g、葱末 10g、生抽 1.5 勺（约 15ml）、料酒 1 勺、盐 3g、糖 3g、白胡椒粉 1g、芝麻油 1 勺。
  - 想要肉馅更"鲜肉"风格：葱姜减半；想要接近饺子馅风格：葱姜加倍。
- **打水用料（多汁的关键）**：
  - 高汤 60-80ml（或浓汤宝半块+15ml 热水化开+15ml 常温水），分次使用。
- **（可选）低脂改良版**：
  - 复配食品增稠剂按说明调糊：10ml 冷水调糊+25ml 开水搅成半透明凝胶，冷却后混入 280g 纯瘦肉糜+15g 融化猪油。
  - 用凝胶模拟肥肉的多汁口感，脂肪大幅降低。
- **（可选）提鲜加料**：
  - 泡发香菇丁 3 朵、冬笋丁 30g、皮冻丁 50g（爆汁版）、虾仁丁 50g。
- **工具**：蒸笼、蒸笼垫/油纸/白菜叶。

## 详细做法

1. **调馅打底**：
   - 猪肉末加姜末、葱末、生抽、料酒、盐、糖、白胡椒粉。
   - 用筷子顺**一个方向**搅拌 2 分钟至发黏上劲。
2. **打水**：
   - 高汤分 3-4 次加入，每次 15-20ml，顺同一方向搅到水分完全被吸收再加下一次。
   - 判断标准：肉馅亮晶晶、呈胶质黏稠状，挖一勺倒扣不掉。
   - 太稠就补 5ml 水继续搅；打完水加芝麻油封住水分。
   - 拌入香菇丁等加料，冷藏 30 分钟让味道融合、馅更好包。
3. **包制**：
   - 皮放手心，中间放 25-30g 馅，用勺背把馅压实。
   - 另一只手虎口收拢皮的边缘，边转边轻轻掐出褶皱，**顶部不封口**，露出一点馅心。
   - 虎口抹点油再收口，不粘手。
   - 底部在案板上墩平，能站稳不倒。
4. **摆笼**：
   - 蒸笼垫油纸/白菜叶/蒸笼垫，烧卖间隔 2cm 摆放（蒸后会膨胀）。
5. **蒸制**：
   - 蒸锅水**烧开后再上笼**，大火足汽蒸 8-10 分钟。
   - 冷冻保存的烧卖无需解冻，直接蒸 12-15 分钟。
6. **出锅**：
   - 关火后立刻开盖取出（焖着会让皮吸水变塌）。
   - 稍晾 1 分钟，配玫瑰米醋、姜丝或辣酱食用。

## 关键技巧

1. **打水是多汁的唯一秘诀**：
   - 分次加高汤、顺向搅到吸收，肉馅形成持水的胶质网络，蒸出来才一包汤。
   - 不打水的肉馅蒸完干柴发渣，是新手烧卖翻车的首因。
2. **顺一个方向搅**：
   - 乱搅会破坏肉蛋白形成的网状结构，馅发散不上劲。
3. **皮馅比 1:2-1:2.5**：
   - 皮 10-15g 配馅 25-30g，馅少了像吃面皮，馅多了收不拢、蒸后塌腰。
4. **水开再上笼**：
   - 冷水上笼，皮子长时间受热吸水，蒸完塌成一团；沸水足汽，皮迅速定型挺括。
5. **蒸好即取出**：
   - 关火焖在锅里，蒸汽回滴把皮泡软；立刻出笼才能保持"皮挺馅嫩"。
6. **做多冷冻囤粮**：
   - 包好的烧卖摆盘冷冻定型后装袋，-18℃ 存 1 个月；吃时无需解冻直接蒸 12-15 分钟。

## 常见问题

1. **肉馅干柴没有汤汁**：
   - 原因：没打水或打水没吸收。
   - 解决：严格分次打水至胶质状；进阶版拌入 50g 皮冻丁，蒸后化成汤汁。
2. **蒸完破皮露馅**：
   - 原因：皮太薄/太干，或收口捏死了。
   - 解决：皮边缘擀薄中间留厚；烧卖顶部本就不封口，靠虎口收拢定型而非捏死。
3. **烧卖蒸塌、东倒西歪**：
   - 原因：冷水上笼、摆得太挤、馅太稀。
   - 解决：水开上笼、间隔 2cm、馅打足水上劲；出锅前用筷子轻扶扶正。
4. **皮边发硬发白**：
   - 原因：皮暴露在空气中风干，或蒸制时锅盖滴水。
   - 解决：包的过程皮盖湿布；锅盖包一层纱布吸水。

## 变化做法

1. **糯米烧卖**：
   - 糯米 250g 隔夜泡后蒸熟，与炒香的肉糜、香菇丁、笋丁加生抽老抽糖同炒成馅。
   - 包法相同，是江浙早餐摊的扛把子。
2. **虾仁鲜肉烧卖**：
   - 每个烧卖顶部塞半只虾仁再蒸，虾变红即熟。
   - 广式"烧卖皇"路线，鲜上加鲜。
3. **煎烧卖**：
   - 蒸熟的烧卖放凉，平底锅少油中火把底部煎脆。
   - 一卖两吃，底部焦脆上部软糯，像生煎的迷你版。

# 糖拌西红柿

## 食材准备与处理

**主料：**

- 西红柿 2-3 个（约 500g）：**选熟透的沙瓤西红柿**——捏起来软硬适中有弹性、底部有放射状裂纹、闻着蒂部有浓郁果香。硬邦邦的催熟西红柿酸涩少汁，怎么做都不好吃。

**调料：**

- 白砂糖 30-45g（2-3 勺）：粗砂糖更佳，颗粒在口中慢慢融化，口感有层次。
- 可选点睛：盐 0.5g（一小撮，激发甜味）、白醋几滴。

**工具：**

- 冰箱（冷藏用）。

**预处理关键：**

1. 划十字：西红柿洗净，用刀在顶部（花蒂对面）划米字型浅口，深度以划破皮为准，不要伤到果肉。
2. 烫皮：方法一——用筷子插入西红柿蒂部，在燃气灶明火上转动烤 10 秒，至皮卷边炸裂；方法二——放入碗中浇开水烫 30 秒。两种方法都能让皮肉分离。
3. 撕皮：从划口处轻松撕去整张外皮。去皮后口感细腻无渣，糖也更容易渗入；喜欢带皮的脆感可以省略 1-3 步，直接洗净切块。
4. 切块：去蒂后切成 1cm 厚的瓣或滚刀块，**顺着果腔隔膜下刀**，瓣形完整、汁水不易流失。厚度控制在 1cm 左右：太薄一拌就烂，太厚糖腌不透。

**提示：**

- 用不锈钢刀或陶瓷刀切，避免金属异味影响西红柿的清新风味。

- 夏季本地露天西红柿风味最佳；冬季温室果寡淡，不建议做这道菜。

- 绵白糖融化最快，粗砂糖口感更有层次，二选一即可。

## 详细做法

1. 铺第一层：取一个深盘，将切好的西红柿均匀码一层，尽量不要重叠挤压。

2. 撒第一层糖：均匀撒上一层白砂糖（约总量的一半）。

3. 重复码放：继续码第二层西红柿，再撒一层糖，直到全部放完。**分层撒糖比顶部堆糖融化更均匀**。

4. 加一撮盐（可选）：最后撒一小撮盐（0.5g），盐能对比出甜味、抑制酸味，是"糖拌更甜"的味觉魔法，量绝不能多。

5. 冷藏腌制：盖上保鲜膜，放入冰箱冷藏 15-30 分钟。低温让糖慢慢融化、西红柿渗出汁水，糖汁交融形成酸甜汤汁。

6. 上桌：取出直接食用。汤汁是精华，吃完西红柿记得喝掉。

## 关键技巧

1. 沙瓤熟果是灵魂：糖拌西红柿没有任何烹饪手段修饰，100% 靠原料。自然熟沙瓤西红柿酸甜平衡、汁水充沛；硬果催熟果拌出来只有酸和渣。

2. 去皮口感升级：烫皮撕掉后，果肉直接裹糖，入口即化没有皮的韧性干扰；且皮上的蜡质和农残一并去除。

3. 顺纹理下刀：沿果腔隔膜切瓣，细胞壁破坏少，汁水留在果肉里；乱刀切碎，汁水全流到盘里，果肉发柴。

4. 分层撒糖：每层薄撒，糖与果面接触面积大，融化快且均匀；一把糖堆顶上，上层齁甜下层无味。

5. 一撮盐提味：微量的钠离子能放大甜味受体敏感度，并中和部分酸感，是甜品行业公开的秘密。

6. 冰镇出汁才好吃：冷藏 15-30 分钟是风味质变期——糖化开、汁渗出、温度降下来，冰凉爽口；拌完立刻吃，糖还是颗粒、味道没融合。

## 常见问题

1. 酸得倒牙？西红柿太生或糖不够。换沙瓤熟果，糖加量到 45g，加一撮盐中和。

2. 果肉发柴没汁？买了催熟硬果，或切太碎。选软熟沙瓤果，切 1cm 厚瓣，顺纹理下刀。

3. 糖不化、满口颗粒？没冷藏静置。冷藏 15-30 分钟让糖融化出汁；急吃可用细砂糖代替粗砂糖。

4. 出汤太多果肉软烂？腌制时间太久（超过 2 小时）或反复翻动。腌好即食，轻拿轻放不搅拌。

5. 皮撕不干净？烫皮时间不够。开水烫足 30 秒，或明火烤到皮卷边，过一下凉水再撕更轻松。

6. 西红柿带青肩发硬？没熟透。室温放 1-2 天催熟后再做，青硬部分直接切掉不用。

## 变化做法

1. 蜂蜜桂花版：白砂糖换成蜂蜜 20ml，撒干桂花少许，冷藏后食用，花香蜜甜，颜值和风味双升级。

2. 话梅风味版：加 2 颗话梅（去核切碎）同腌，话梅的咸酸与糖的甜交织，开胃解腻，潮汕风味。

3. 雪山盖顶（宴客版）：西红柿整只去皮，顶端切十字花刀不切断，翻开成莲花状，堆上大量白糖如雪，宴席凉菜的经典造型。

4. 番茄糖拌黄瓜：黄瓜半根切片与西红柿同拌同腌，双脆合璧，红绿相间更开胃。

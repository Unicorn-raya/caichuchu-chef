# 葱油桂鱼

## 食材准备与处理

**主料**

- 桂鱼（鳜鱼）1 条（约 500-750g）：尽量买活鱼现杀，去内脏时用一次性手套操作更卫生。

**鱼的处理（去腥三件套）**

1. 将鱼身表面所有鳞片刮干净（桂鱼细鳞多，可用小刷子刷）。
2. 用厨房纸把鱼肚子里的贴骨血和黑膜擦干净——贴骨血影响口感，黑膜是鱼腥味来源。
3. 用菜刀在鱼身表面来回刮几次，刮掉黏液，进一步去腥。
4. 用清水将鱼内外冲洗干净。

**改刀**

1. 鱼内外水分用厨房纸擦干，鱼头朝左、尾朝右平放。
2. 从鱼鳃边开始每隔 3cm 纵向划一刀，深度达到脊椎骨即可。
3. 另一面同样处理。

**浸泡去腥（可选但推荐）**

- 改好刀的鱼放入葱姜料酒水中泡 15 分钟，取出彻底控干水分。

**辅料切配**

- 姜 1 块（约 50g，鸡蛋大小）：削皮后切 3mm 厚姜片。
- 葱 2-3 根：葱白切段垫盘底，葱绿切细丝。
- 红椒少许：切丝（点缀用）。
- 葱丝红椒丝切好后泡冰水 10 分钟，会自然卷曲更好看。

**调味**

- 蒸鱼豉油 3 勺（可兑半勺温水+少许糖提鲜）。
- 食用油少许（或猪油一勺，蒸鱼更香更嫩）。

## 详细做法

1. **装盘**
   - 盘中确保无多余水分，葱白段垫在盘底（垫高鱼身让受热均匀）。
   - 放上桂鱼，姜片码在鱼身和刀口里，鱼肚内也塞 1-2 片姜。
   - 鱼身表面淋少许食用油。
2. **烧水**
   - 蒸锅加足量清水，大火烧到水开上汽。
   - **必须水开后再放鱼。**
3. **蒸鱼**
   - 放入鱼盘，大火蒸 8-12 分钟（500g 左右 8 分钟，750g 以上 10-12 分钟）。
   - 关火焖 2 分钟。
   - 判断标准：用筷子戳鱼背最厚处，能轻松穿透且无血水即熟。
4. **倒腥水**
   - 取出鱼盘，把盘中蒸出来的水全部倒掉（这水很腥）。
   - 捡掉姜片和垫底的葱白。
5. **铺丝淋豉油**
   - 鱼身上铺卷曲的葱丝、红椒丝。
   - 沿盘边淋一圈蒸鱼豉油。
6. **泼热油**
   - 另起锅烧 3 勺食用油，烧到油冒烟（约七八成热）。
   - 关火，均匀泼在葱丝上，"滋啦"一声激出葱香，立即上桌。

## 关键技巧

1. **水开再上锅**：冷水上锅会让鱼肉在低温区停留太久，肉质发柴；水开后大火快蒸，鱼肉才嫩。
2. **蒸鱼水必须倒掉**：盘中积水是腥味集中地，不倒掉直接淋豉油会腥。
3. **泼油温度要够**：油烧到冒烟再泼，才能瞬间激出葱丝香气；油温不够葱丝是"生"的，只有葱臭没有葱香。
4. **蒸制时间按鱼的大小定**：每 100g 大约 1.5 分钟，宁可少蒸 1 分钟用余温焖熟，也不要超时——蒸老的桂鱼肉柴刺硬。
5. **豉油沿盘边淋**：不要直接浇在鱼身上，鱼肉蘸着豉油吃咸淡更均匀，卖相也干净。
6. **鱼身抹油再蒸**：薄薄一层油能锁住鱼肉水分，蒸出来更滑嫩，这是粤菜蒸鱼的标准手法。

## 常见问题

1. **鱼肉腥**：黑膜、贴骨血、黏液没处理干净，或蒸鱼水没倒。重做去腥三件套。
2. **鱼肉老柴**：蒸过头了。500g 的鱼 8 分钟足够，关火焖 2 分钟用余温补足。
3. **葱丝泼油后不香**：油温不够。油要烧到冒烟（约 200°C），关火立即泼。
4. **鱼皮破裂、卖相差**：蒸之前水没烧开放鱼，或鱼身带水下锅。水开上锅、鱼身擦干。

## 变化做法

1. **清蒸桂鱼**：不泼葱油，蒸好后直接淋蒸鱼豉油，突出鱼肉本味，口味更清淡。
2. **葱油鳜鱼（加洋葱版）**：葱油里加 1/4 个洋葱丝同炸至金黄，滤出葱油再泼，葱香层次更厚。
3. **豉油皇蒸桂鱼**：蒸鱼豉油加小火爆香的姜末、少许冰糖煮一下再淋，酱汁更复合。

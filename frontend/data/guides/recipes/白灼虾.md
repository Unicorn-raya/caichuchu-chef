# 白灼虾

## 食材准备与处理

**主料：**

- 活虾 500g（基围虾、明虾均可）：白灼做法调料极少，全靠食材本味，必须选活蹦乱跳的鲜虾；冰鲜虾次之，死虾软壳虾不要做白灼。
- 清洗：活虾用清水快速冲洗 1-2 遍即可，不要久泡，避免虾肉吸水变淡。
- 去虾线（可选但推荐）：用牙签从虾背第二节处插入，轻轻挑出黑色虾线；或剪掉虾头尖刺后轻挤虾身，捏住虾尾把线带出。虾线是消化道，有泥沙和腥味。
- 剪须（可选）：剪掉虾须、虾枪和虾腿，吃起来更干净利索。
- 处理完的虾控水备用，并尽快烹饪（活虾去线后久放虾肉会松散）。

**煮虾料：**

- 洋葱 1 头切小块（或大葱段）、姜 4-5 片、料酒 15ml。

**蘸料：**

- 姜末 5g、蒜末 5g、葱花适量、芝麻少许。
- 酱油 20ml、蚝油 5g、香醋 5ml、食用油 15ml。
- 也可以只备纯香醋，吃虾的本味。

## 详细做法

**方式一：无水焗法（本菜谱原味版）**

1. 底料铺锅：洋葱小块和姜片平铺在平底锅底部。

2. 铺虾：控好水的虾均匀铺在洋葱姜片上。

3. 加酒：沿锅边倒入料酒 15ml。

4. 焖制：盖上锅盖，中火 1 分钟，转小火 5 分钟，关火后再焖 5 分钟。全程不加水，靠虾自身水分和料酒产生的蒸汽把虾焖熟，鲜味一点不流失。

5. 出锅：虾身完全变红、弯曲成 C 形即可出锅，用干净盘子装好。

**方式二：沸水白灼法（经典版）**

1. 烧水：锅中加足量水（水量要多，虾下锅后水温不会骤降），放入姜片、葱段、料酒 15ml，大火烧开至翻滚冒大泡。

2. 下虾：水完全沸腾后放入虾，保持大火。

3. 控时：虾身完全变红、虾尾弯曲成 C 形立即捞出。5-7cm 小虾约 90 秒，8-10cm 中虾约 2-2.5 分钟，12cm 以上大虾 3 分钟封顶。

4. 过冰水（加分项）：捞出的虾立刻浸入冰水 30-60 秒，虾肉瞬间收缩，更紧实 Q 弹，且壳肉分离好剥壳。

**蘸料做法：**

1. 姜末、蒜末、葱花、芝麻放入小碗。

2. 15ml 食用油烧到微微冒烟，浇在姜蒜末上激香。

3. 加酱油 20ml、蚝油 5g、香醋 5ml 搅匀即可。

## 关键技巧

1. 沸水下锅，绝不冷水下锅：沸水下锅虾肉表层蛋白质瞬间凝固，锁住约 85% 的汁水，虾肉鲜嫩 Q 弹；冷水下锅加热慢，汁水大量流失，肉质发柴发韧，腥味还会反渗进虾肉。

2. 时间按大小卡死：中等虾水开后 1.5-2 分钟是黄金区间，看到虾身变红弯曲成 C 形就捞；蜷成 O 形说明已经过熟。

3. 过冰水让口感升级：热胀冷缩让虾肉更紧实弹牙，还能让壳肉分离，剥壳不粘肉。

4. 去腥三件套就够：姜、葱、料酒足矣；煮虾的水里不要加盐，盐会让虾肉脱水变老。

5. 无水焗法更鲜甜：不加水靠蒸汽焖熟，虾的鲜味不会被水稀释带走，这是无水焗相对水煮的最大优势；但开始不能大火，防止糊底。

6. 锅盖有通气口要加时：焖法里如果锅盖有气孔，蒸汽流失快，中火阶段增加 30 秒。

## 常见问题

1. 虾肉柴、咬不动？煮/焖太久是最常见原因。虾熟得极快，变红弯 C 就出锅；其次是冷水下锅慢煮导致水分流失。

2. 虾有腥味？虾不新鲜、没去虾线，或没放姜酒。白灼对鲜度要求极高，活虾现买现做。

3. 虾头发黑？虾不新鲜或煮好后久放。虾头中的酪氨酸酶会氧化变黑，不影响安全但影响卖相，尽快食用。

4. 无水焗糊底了？开始火太大或锅底太薄。中火起步，用厚底不粘锅，料酒要足量。

5. 剥壳粘肉、不好剥？没过冰水。冰水激 30 秒，壳肉自然分离，一剥到底。

## 变化做法

1. 广式白灼+豉油皇蘸料：蘸料用蒸鱼豉油+白糖+清水煮开放凉，加葱姜丝浇热油，是茶楼标准配法。

2. 泰式酸辣蘸料：鱼露 15ml + 青柠汁 10ml + 蒜末 + 小米辣 + 少许糖，酸辣清爽，夏天绝配。

3. 盐水煮法：水中加足量盐（约 10g/L）、花椒几粒、姜片，煮好的虾带淡淡咸香，不用蘸料直接吃，北方家常做法。
